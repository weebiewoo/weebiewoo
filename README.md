# Hugo Low

C++ engine programmer studying Computer Science (Interactive Media and Game Development) at SIT and DigiPen Singapore. Looking for an IWSP placement from May 2027.

## Crucible Engine (team project, Sep 2026 – present)

[kwan-c/Crucible-Engine](https://github.com/kwan-c/Crucible-Engine): a C++23 / Vulkan 1.3 game engine and editor built by Team Medium-Well (8 people) alongside our co-op horde shooter, Lithomachia.

What I built:

- **Enemy AI tools**: a visual state-graph and behaviour-tree editor our designer uses to script enemies without C++. Nodes are C# scripts that appear in the editor's menus automatically; graphs save as versioned JSON. [Engine/src/AI](https://github.com/kwan-c/Crucible-Engine/tree/main/Project/Crucible%20Engine/Engine/src/AI), [Editor/src/Graph](https://github.com/kwan-c/Crucible-Engine/tree/main/Project/Crucible%20Engine/Editor/src/Graph)
- **Physics** on Jolt Physics: multithreaded 60 Hz fixed step, triggers and collision events, raycasts, a character controller and 4 joint types. [Engine/src/Physics](https://github.com/kwan-c/Crucible-Engine/tree/main/Project/Crucible%20Engine/Engine/src/Physics)
- **Audio** on the FMOD Core API, modelled on Unity's AudioSource, AudioListener and mixer groups. [Engine/src/Audio](https://github.com/kwan-c/Crucible-Engine/tree/main/Project/Crucible%20Engine/Engine/src/Audio)
- **Logger and input**: 3 log outputs plus a scoped timer; keyboard, mouse and gamepad on GLFW. [Engine/src/Diagnostics](https://github.com/kwan-c/Crucible-Engine/tree/main/Project/Crucible%20Engine/Engine/src/Diagnostics), [Engine/src/Input](https://github.com/kwan-c/Crucible-Engine/tree/main/Project/Crucible%20Engine/Engine/src/Input)
